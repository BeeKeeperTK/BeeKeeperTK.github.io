Controls / 조작법

8-Way Movement (이동)WASD
Run (달리기)Left Shift
Dodge Roll (구르기 회피)F
Liberate Card (제단 상호작용)Spacebar
Drop Weapon (무기 버리기)Q
Swap Weapon / Replenish Arrows (무기 교체 / 화살 보충)T
Attack (공격)Left Mouse Button
Pause Menu (일시정지)ESC

Vessel 은 고대 유적 지하에서 깨어난 빈 인간 육체 'Deck' 이 되어, 던전에 봉인된 자아를 가진 무기 카드들을 구출하고 실시간으로 무기를 교체하며 싸워나가는 2D 탑다운 액션 프로토타입입니다.
